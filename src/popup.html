Welcome to YANSII

A passive security scanner that inspects the pages you browse and points out potential issues to verify by hand. For authorized security testing only.

  1. Set your target scope below to limit scanning to authorized domains
  2. Browse any website — scanners run automatically in the background
  3. Check the Dashboard for findings grouped by domain and severity

Optional: Add an AI API key for deeper analysis. Scanners work without AI.
